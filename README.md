## Overview

**30 Days of Web Development** is an intensive engineering challenge dedicated to mastering the core fundamentals of web development without heavy frameworks or abstractions. By building small, interactive applications from scratch, this repository demonstrates core competence in DOM manipulation, asynchronous JavaScript, Web Audio API, responsive layout architecture, and real-time state management.

## Features

- **Framework-Free Vanilla Code**: Pure HTML5, modern CSS3 (Flexbox/Grid), and ES6+ JavaScript with zero third-party framework overhead.
- **Event-Driven Interactions**: Deep utilization of DOM event listeners, keyboard accessibility, and dynamic class toggling.
- **Asynchronous Data Integration**: Real-world API integration using JavaScript `fetch`, Promises, and async/await syntax.
- **Responsive Layout Design**: Mobile-first design patterns adapting seamlessly from mobile viewports to desktop resolutions.
- **Instant Deployment**: Deployed and served globally via GitHub Pages with zero build latency.

## Tech Stack

- **Markup**: Semantic HTML5 (Header, Nav, Section, Article, Footer)
- **Styling**: Vanilla CSS3, CSS Custom Properties (Variables), Flexbox, Grid, Keyframe Animations
- **Programming Language**: Vanilla JavaScript (ES6+, DOM APIs, Event Loop, LocalStorage, Web Audio)

## Local Development

### 1. Clone the repository
```bash
git clone https://github.com/hritikkumarpd/hritikkumarpd.github.io.git
cd hritikkumarpd.github.io
```

### 2. Run with Live Server
Open `index.html` directly in your browser, or run a local static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```

Open `http://localhost:8000` in your web browser.
